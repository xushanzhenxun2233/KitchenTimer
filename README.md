# 厨房计时器 (KitchenTimer)

一款专为厨房烹饪场景打造的 Android 原生多菜并行计时软件（Kotlin + Jetpack Compose）。

## 核心特性

- **菜谱预设与完全自定义流程**
  - 内置常见菜谱（溏心蛋、红烧肉、清蒸鲈鱼、手冲咖啡），支持新建、编辑、删除并本地持久化保存。
  - 每个菜谱支持**自定义任意数量的烹饪流程**，可自由增删步骤、调整顺序，并为每一步分别设定名称与 `时 / 分 / 秒`（附 `+10秒 / +30秒 / +1分 / +5分` 快捷按键）。
- **多道菜同时计时**
  - 支持同时开启多道菜独立倒计时（例如一边炖汤一边炒菜），卡片清晰展示当前流程、超大等宽倒计时数字、进度条与下一步预告。
  - 到时响铃的卡片自动置顶并红橙脉冲高亮，一眼识别。
- **手机默认铃声响铃 + 震动**
  - 自动调用手机系统默认闹钟铃声（回退系统默认来电铃声 / 通知提示音），通过闹钟音频通道循环播报并配合震动提醒。
  - 到时后需**手动确认**进入下一步（提供「停止响铃 · 下一步」「仅停响铃」「+1分继续」「改时间」），贴合做菜实际节奏。
- **屏幕常亮**
  - 应用打开期间默认保持手机屏幕常亮（`FLAG_KEEP_SCREEN_ON`），顶部状态栏可随时切换常亮开关。
- **后台被杀自动恢复**
  - 实时持久化运行中的计时任务与目标结束时间戳；应用被系统清理后重新打开时，自动按真实流逝时间恢复所有未完成的倒计时（若后台期间已到点则直接提醒），并保留最近记录供手动恢复。
- **全前台按钮防误触设计**
  - 所有前台操作按钮均采用**两段式防误触**（首次点击高亮提示「再点确认」，内置 `250ms` 手抖连点过滤，2.5 秒内未确认自动复原），厨房湿手操作不误触。
- **灵活修改当前步骤时间**
  - 计时过程中可随时点击「改时间」调整当前流程剩余时长，支持精确输入与快捷微调。

## 安装使用

前往本仓库的 [Releases](../../releases) 页面下载最新 APK 安装包（支持 Android 8.0 / API 26 及以上设备）。

## 本地构建

```bash
# Windows
.\gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 技术栈

- **语言**：Kotlin 2.0
- **UI**：Jetpack Compose + Material 3
- **架构**：MVVM (`ViewModel` + `StateFlow`)
- **存储**：本地 JSON 文件持久化（零重型外部依赖）
- **系统能力**：`WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON`、`RingtoneManager`、`MediaPlayer (USAGE_ALARM)`、`Vibrator`
